# Hydrion Security Policy

## Reporting

Please report a suspected vulnerability privately to `hydrionsharks@gmail.com`.
Do not include production credentials, signing keys, private health data, or
other users' data in an issue or public discussion.

Include the affected Hydrion version, platform, impact, and minimal reproduction
steps. The maintainers will acknowledge the report, assess severity, and
coordinate a fix and disclosure where appropriate.

## Supported Release

Security fixes target the newest published Hydrion release candidate and the
current `main` branch. Older prerelease artifacts may be superseded rather than
patched independently.

## Release Material

Android keystores, Apple certificates and provisioning profiles, store
credentials, API keys, and CI tokens must never be committed. Release artifacts
must be generated by the protected release workflow, validated before upload,
and accompanied by source/version metadata and SHA-256 checksums.
